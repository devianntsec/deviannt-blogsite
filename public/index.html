CVE-2021-4034 · PwnKit: Local Privilege Escalation in polkit's pkexec

CVE-2021-4034 is a local privilege escalation vulnerability (CVSS 7.8) in polkit's pkexec utility. An out-of-bounds write triggered by argc=0 allows any unprivileged local user to inject a malicious shared library through glibc's gconv infrastructure and execute arbitrary code as root. The bug went undetected for over 12 years across all major Linux distributions.

CVE-2024-30051 · Heap Overflow in Windows DWM: from an Integer Division Bug to SYSTEM

CVE-2024-30051 is an Elevation of Privilege (CVSS 7.8) in the Windows Desktop Window Manager. A single integer division error in dwmcore.dll produces a deterministic heap overflow of 0x8F bytes that loads an attacker-controlled DLL inside dwm.exe — running at Integrity Level SYSTEM — from any unprivileged local user session.

%b %e, %Y Security, Windows

CVE-2024-51324 · BYOVD: Three Undocumented Kernel Primitives in BdApiUtil64.sys

CVE-2024-51324 is a BYOVD vulnerability in BdApiUtil64.sys from Baidu Antivirus v5.2.3.116083. Any user can send IOCTLs to the unprotected device object. Ghidra reverse engineering reveals the actual mechanism — PsLookupProcessByProcessId + ObOpenObjectByPointer(KernelMode), not ZwOpenProcess — and two primitives with no prior public documentation: arbitrary file deletion and in-use file deletion with SectionObjectPointer bypass.

%b %e, %Y Security, Windows

CVE-2025-55182 · React2Shell: RCE in React Server Components via Prototype Pollution

CVE-2025-55182 is a critical (CVSS v3.1: 10.0) remote code execution vulnerability in React Server Components. An unauthenticated attacker poisons Object.prototype through the Flight deserializer and injects arbitrary JavaScript executed server-side via the Function constructor. The result is exfiltrated through the X-Action-Redirect HTTP header. No authentication required. Deterministic. Affects React 19.0.0–19.2.0. Patched in React 19.0.1, 19.1.2, and 19.2.1 (December 3, 2025).

%b %e, %Y Security, Web
